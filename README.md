# LockedIn

LockedIn is a mobile app focused on completing daily tasks set by the user to earn back screen time. This is designed
to encourage a focused environment and decrease screen time by forming the habit of viewing doomscrolling as a finite
resource.

# Design
<strong>Tech Stack</strong>
Expo (React Native) Frontend -> FastAPI (Python) Backend -> MongoDB Database

<strong>Features</strong>

- Users can create tasks, which they can either submit a screen time reward for manually or have automatically assign by an AI judge.

- Users can view statistics involving trends related to tasks completed per day, screen time earned, etc.

- Users can toggle which apps are locked by the app
